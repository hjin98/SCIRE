# SCIRE: Scientific Collaborative Inquiry and Reasoning Environment

SCIRE is a proposed persistent, collaborative environment in which human researchers and AI agents develop, examine, revise and preserve scientific understanding: arguments, questions, competing explanations, evidence and the history of discovery.

## Status

SCIRE is in conceptual design. There is no implementation yet, and neither its scientific semantics nor its architecture is accepted-current. The latest proposals are review candidates awaiting independent concept-level review and human decisions. See [`workplans/README.md`](workplans/README.md) for the documents and their lineage.

## Method

Development follows the Scientific Software Development Protocol (SSDP) 7.2.1. Agents and contributors should start with [`AGENTS.md`](AGENTS.md).
